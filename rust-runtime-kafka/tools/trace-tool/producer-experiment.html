        Producer differences
        
        
        Classic Java: blue solid. Native / Panama: orange dashed. Every chart uses the same time window and scale for both producers. Lines stop after a run ends.
        
        
        
        
        

        Acknowledged records
        Records acknowledged when the application consumes delivery, on a shared bucket grid.
        

        Offered records
        Actual offers, including attempts that are permanently refused. Closed-loop feedback can change this curve.
        

        Accepted records
        Records admitted by each producer. Admission refusals never become deliveries.
        

        Refused offers
        Permanent refusals assigned to the original offer time. Includes startup metadata and resource pressure.
        

        Accepted-record failures
        Terminal failed deliveries. Java failure does not establish whether a write was applied.
        

        Outstanding accepted records
        Accepted minus all consumed deliveries, measured at the end of each bucket.
        

        Produce requests at broker
        Complete Produce requests received by the shared broker, including retry requests.
        

        Records appended at broker
        New append records; deduplicated retries do not add a second commit.
        

        Client wire bytes
        Successful local write completions, including control traffic and retry bytes.
