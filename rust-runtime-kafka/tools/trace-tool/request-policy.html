Does broker-ready gathering pay off?

Sealed gathers completed partition batches. BrokerReady can also finish younger, already encoded batches on the same broker and lane, waiting at most one encoder pass. Both use compression-aware batch targets. This comparison measures whether that extra preparation saves requests without costing delivery latency or admission.

The native policies were rerun with deterministic replay. Java is the frozen seed-0 reference from the preceding Full comparison. Successful latency excludes refusals and failed deliveries. Closed-loop traffic waits for deliveries to free source slots; a faster client can offer and acknowledge more records. Open-loop traffic keeps its scheduled offer rate. Compare populations before interpreting latency or byte totals.
